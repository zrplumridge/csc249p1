instructions discussed with Emi Neuwalder, ideas discussed with Vivian Streber

Input: "int" "any number of words"
Puts all words into uppercase then
Repeats int times (defaults to 5 times if no int provided or if int > 20)
5 hello -> HELLO HELLO HELLO HELLO HELLO

Encoding is in bytes with utf-8. 
Input on client end must be a string. If input is "quit" then program will be cancelled. 
Server must return a string. 
Server info: HOST = "127.0.0.1"  # This is the loopback address
PORT = 65432        # The port used by the server
At most 1024 bytes will be read on either side.
